## 写作要求
1. 文案必须与帧分析中的场景描述内容一致——不要虚构画面中不存在的内容
2. 自然地串联相邻帧的内容，形成流畅的叙事
3. 使用${style}风格的语调——正式但不僵硬
4. 每段解说对应一个帧组（约3-5个连续帧），段落之间用空行分隔
5. 在合适位置加入过渡词语，避免生硬的场景切换
6. 总时长与帧分析覆盖的视频长度匹配

## 输出格式
请严格按照以下 JSON 格式输出，不要包含其他内容：

```json
{
  "items": [
    {
      "picture": "画面描述文字",
      "narration": "对应的解说文案",
      "timestamp": "HH:MM:SS-HH:MM:SS",
      "OST": 2
    }
  ]
}
```

字段说明：
- `picture`: 该片段对应的画面内容描述（字符串）
- `narration`: 详细的解说文案，与画面内容相关（字符串）
- `timestamp`: 时间范围，格式 HH:MM:SS-HH:MM:SS（字符串）
- `OST`: 音频类型，固定为 2（混合模式，整数）

确保：
- 输出是合法的 JSON，items 数组的每个元素包含上述四个字段
- items 数组按时间顺序排列
- 不添加 JSON 标准格式之外的任何注释或标记
