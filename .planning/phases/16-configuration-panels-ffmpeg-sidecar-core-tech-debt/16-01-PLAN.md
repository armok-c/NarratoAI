  <action>
    创建 `src-tauri/src/commands/config.rs`，包含 5 个 #[tauri::command] 异步函数。每个函数遵循现有 system.rs 的错误处理模式（Result<T, CommandError>）。

    命令 1 — `get_config(app_config: State<'_, AppConfig>) -> Result<serde_json::Value, CommandError>`：
    - 从 Tauri State 读取 AppConfig
    - 序列化为 serde_json::Value
    - 对以下字段做脱敏处理: vision_openai_api_key, text_openai_api_key, azure.speech_key, tencent.secret_id, tencent.secret_key, soulvoice.api_key, tts_qwen.api_key, doubaotts.ak, doubaotts.sk, doubaotts.token
    - 脱敏逻辑（per D-31）：len <= 8 时 return "****"；否则取前3后3字符，格式 `{prefix}...****...{suffix}`
    - 返回完整 AppConfig JSON

    命令 2 — `save_config(updates: serde_json::Value, config_manager: State<'_, ConfigManager>) -> Result<(), CommandError>`：
    - 接收增量更新 JSON（仅含用户修改的字段，per D-31 增量语义）
    - 如果 updates 含 vision_openai_api_key 且值为空字符串 `""` → 视为清除该 key
    - 从 ConfigManager 获取 Arc<RwLock<AppConfig>>，通过 `config_manager.config()` 方法
    - 获取写锁，合并 updates 到当前 AppConfig
    - 序列化为 TOML 并写回 config.toml 文件路径（可使用 `toml::to_string_pretty`，注释丢失为已知限制 AI 在下一 task 可改进，此处先用标准 toml 序列化）
    - 合并规则：仅覆盖 updates 中存在的顶层 key，不修改未发送字段

    命令 3 — `test_llm_connection(provider: String, model: String, api_key: String, base_url: String) -> Result<String, CommandError>`：
    - 通过 reqwest 发送测试请求到 OpenAI 兼容 `/v1/chat/completions` 端点
    - 设置 timeout 15 秒
    - 请求体: `{ model: "<model>", messages: [{ role: "user", content: "Hi" }], max_tokens: 5 }`
    - 成功返回 "连接成功"，失败返回具体错误信息

    命令 4 — `get_edge_tts_voices(app_config: State<'_, AppConfig>) -> Result<serde_json::Value, CommandError>`：
    - 检查 `app_config.proxy.enabled` 和 `app_config.proxy.https`
    - 使用 reqwest 调用 Edge-TTS voice list API: `GET https://speech.platform.bing.com/consumer/speech/synthesize/readaloud/voices/list`
    - 如果代理启用，在 ClientBuilder 上设置 reqwest::Proxy
    - 添加 User-Agent（参考 edge_tts.rs 的 build_user_agent()）
    - timeout 30 秒
    - 返回 JSON 数组（未过滤原始 Edge-TTS voice 列表）

    命令 5 — `get_system_proxy() -> Result<serde_json::Value, CommandError>`：
    - 检测环境变量 HTTPS_PROXY, HTTP_PROXY, ALL_PROXY（大小写不敏感）
    - 返回 JSON：`{ https: String, http: String, env_https: Option<String>, env_http: Option<String>, env_all: Option<String> }`
    - 不包含 config.toml 代理配置（前端可独立调用 get_config 获取）

    所有命令使用 `use serde_json::json!` 宏构造 JSON 值。
    在每个命令顶部添加 `use crate::error::CommandError;`。
