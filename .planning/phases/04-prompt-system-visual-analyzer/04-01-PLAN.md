    创建 `src/prompt/template.rs`，实现基于正则的两遍替换模板引擎（D-05~D-08，对齐 RESEARCH.md 两遍模式）：

    导入：`use regex::Regex;` 和 `use std::collections::HashMap;`

    定义过滤器类型：
    ```rust
    type FilterFn = fn(&str) -> String;
    ```

    创建 `builtin_filters() -> HashMap<&'static str, FilterFn>`，包含以下 6 个过滤器（D-06）：
    - `"upper"` — `|s: &str| s.to_uppercase()`
    - `"lower"` — `|s: &str| s.to_lowercase()`
    - `"title"` — 手动实现：遍历字符，单词首字母大写（按空白字符分割单词），其余保持原样。注意：不能使用 `unicode-reverse` — 中文不需要 title case，仅对 ASCII 字母生效即可。
    - `"strip"` — `|s: &str| s.trim().to_string()`
    - `"truncate"` — 长度 <= 100 返回原串，否则截断前 97 字符 + "..."
    - `"json"` — `serde_json::to_string(s).unwrap_or_else(|_| format!("\"{}\"", s))` — JSON 转义字符串

    实现 `pub fn render(template: &str, vars: &HashMap<&str, &str>) -> Result<String, PromptError>`，严格遵循两遍模式（AI-SPEC pitfall #2 解决方案）：

    第 1 遍 — 变量提取和校验（find_iter，D-07）：
    - 编译正则 `r"\$\{(\w+)\}|\$(\w+)"`，编译失败返回 PromptError::TemplateRender
    - 使用 `captures_iter(template)` 遍历所有匹配
    - 从 `caps.get(1).or_else(|| caps.get(2))` 提取变量名
    - 检查变量名是否在 `vars` HashMap 中
    - 收集所有缺失变量名到 Vec，去重
    - 如果有缺失，返回 `PromptError::TemplateRender(format!("缺少必需参数: {}", missing.join(", ")))`

    第 2 遍 — 变量替换（replace_all）：
    - 使用相同的正则 `replace_all(template, |caps: &regex::Captures| { ... })`
    - 从捕获组提取变量名，从 vars 取值
    - 所有变量已通过第 1 遍保证存在，unwrap_or("") 安全

    第 3 遍 — 过滤器应用：
    - 编译过滤器正则 `r"\$\{(\w+)\|(\w+)\}"`
    - 对第 2 遍结果执行 `replace_all`
    - 从捕获组提取变量名和过滤器名
    - 从 filters 查找过滤器函数，如果找到则应用；否则保留原始文本
    - 注意：过滤器的处理应当在变量替换之后再运行，因为 `${varible|filter}` 在这一遍处理时，变量名已经从第 2 遍的替换中变得"透明"——即第 2 遍已将 `${varible|filter}` 的 `variable` 部分替换为实际值，但保留了 `${...|filter}` 结构。

    实际上，更正确的做法是：在第 2 遍替换 `$variable` 和 `${variable}` 时，保留 `${variable|filter}` 不变（因为正则 `r"\$\{(\w+)\}|\$(\w+)"` 不匹配 `${variable|filter}`——因为 `|` 不是 `\w`）。然后在第 3 遍用专门的过滤器正则处理 `${variable|filter}` 格式。

    添加文字说明：支持转义 `\$` 为字面 `$`（替换时不处理 `\$\{` 或 `\$`）。

    在 `#[cfg(test)] mod tests { ... }` 中添加测试：
    - 基本变量替换 `${variable}` 和 `$variable`
    - 缺失变量返回 PromptError::TemplateRender
    - upper 过滤器正确大写
    - lower 过滤器正确小写
    - title 过滤器正确首字母大写
    - strip 过滤器正确去空白
    - truncate 过滤器正确截断
    - json 过滤器正确转义
    - 多变量混合替换
    - 特殊字符（中文、标点）在占位符值中的处理
