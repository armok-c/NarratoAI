核心函数 `generate_sdp_script()` 编排两步 LLM 调用（D-10）：
1. subtitle_analysis prompt → 分析叙事结构，提取 plot_titles + summary
2. plot_extraction prompt → 基于第一步结果定位具体时间段
然后 `merge_script()` 将 plot_points 合并为 `Vec<ScriptClip>`（全部 OST=1，narration 占位值）。

- `src/sdp/mod.rs` — 模块入口（仅 error/types/script_gen；clip/pipeline 在 Plan 04 添加）

<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| subtitle file → generate_sdp_script | Untrusted subtitle text crosses into LLM prompt |
| LLM JSON output → repair_json | Malformed JSON from LLM could cause parse failures |
| merged_subtitle.json → disk | Script data written to disk |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-004 | DoS | LLM JSON parsing | mitigate | `repair_json` is panic-free (safe unwrap chaining); `parse_script` skips invalid items, errors on empty |
| T-08-005 | Tampering | script output | accept | Script is saved to local path specified by user; no remote/external consumers |
</threat_model>
