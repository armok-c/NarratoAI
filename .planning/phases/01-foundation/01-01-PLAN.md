## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.toml -> AppConfig | 用户可编辑的 TOML 文件传入 serde 反序列化，是不受信输入 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | config.toml 反序列化 | mitigate | serde 反序列化限制为强类型结构体，不执行任意代码；未知字段通过 serde(deny_unknown_fields) 控制（暂不加，保持前向兼容） |
| T-01-02 | Information Disclosure | config.toml 中的 API key | accept | config.toml 已在 .gitignore 中，桌面单用户应用，风险可接受 |
| T-01-03 | Tampering | ConfigWatcher 热加载 | mitigate | 解析失败时仅记录日志不替换当前配置，防止损坏的 TOML 文件覆盖有效配置 |
</threat_model>
