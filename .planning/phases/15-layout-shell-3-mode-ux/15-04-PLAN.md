## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-06 | S (Spoofing) | get_system_stats poll | accept | CPU/RAM 数据来自本地操作系统，无认证必要。`--%` fallback 在出错时显示，不影响应用功能。 |
| T-15-07 | D (Denial of Service) | SystemMonitorBar 2s interval | mitigate | onUnmounted 清理 interval（D-35），防止组件卸载后继续调用。error catch 防止未处理异常导致 interval 中断。 |
| T-15-08 | T (Tampering) | Dynamic Tauri import | mitigate | try/catch 包裹所有动态 import 调用，非 Tauri 环境静默降级。 |
</threat_model>
