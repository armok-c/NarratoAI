    测试分组：

    **describe('isDebugMode')**:
    - it('returns true when DEV mode'): stubGlobal('import.meta', { env: { DEV: true, VITE_DEBUG: undefined } }) → expect true
    - it('returns true when VITE_DEBUG=true'): stubGlobal('import.meta', { env: { DEV: false, VITE_DEBUG: 'true' } }) → expect true
    - it('returns false in production'): stubGlobal('import.meta', { env: { DEV: false, VITE_DEBUG: undefined } }) → expect false

    **describe('filterSensitiveArgs')**:
    - it('removes all 6 sensitive fields from object'): 传入 { apiKey:'k', password:'p', token:'t', secret:'s', api_key:'ak', accessToken:'at', name:'safe' } → expect 返回对象有 name:'safe'，无 apiKey/password/token/secret/api_key/accessToken
    - it('passes arrays through unchanged'): 传入 [1,2,3] → expect 返回 [1,2,3]
    - it('passes primitives through unchanged'): 传入 'string' → expect 返回 'string'；传入 42 → expect 返回 42
    - it('passes null through unchanged'): 传入 null → expect 返回 null

    **describe('debugLog')**:
    - it('calls console.log when debug mode is on'): stubGlobal 使 isDebugMode=true，spyOn console.log，调用 debugLog('msg', {key:'val'}) → expect console.log 被调用，参数包含 'msg'
    - it('does not call console.log when debug mode is off'): stubGlobal 使 isDebugMode=false，spyOn console.log，调用 debugLog('msg') → expect console.log 未被调用
    - it('filters sensitive args from log output'): stubGlobal 使 isDebugMode=true，spyOn console.log，调用 debugLog('msg', { apiKey:'secret', data:'public' }) → expect console.log 的第二个参数对象不包含 apiKey

    **describe('debugError')**:
    - it('calls console.error when debug mode is on'): stubGlobal 使 isDebugMode=true，spyOn console.error，调用 debugError('err', new Error('test')) → expect console.error 被调用
    - it('does not call console.error when debug mode is off'): stubGlobal 使 isDebugMode=false，spyOn console.error → expect console.error 未被调用

    **describe('normalizeTauriArgs')**:
    - it('converts BigInt to Number within safe range'): normalizeTauriArgs(BigInt(42)) → expect 42（typeof number）
    - it('throws on BigInt exceeding MAX_SAFE_INTEGER'): normalizeTauriArgs(BigInt(Number.MAX_SAFE_INTEGER) + BigInt(1)) → expect throw，错误消息包含 '安全整数范围'
    - it('throws on BigInt below MIN_SAFE_INTEGER'): normalizeTauriArgs(BigInt(Number.MIN_SAFE_INTEGER) - BigInt(1)) → expect throw
    - it('recursively normalizes nested objects'): normalizeTauriArgs({ a: BigInt(1), b: { c: BigInt(2) } }) → expect { a: 1, b: { c: 2 } }
    - it('recursively normalizes arrays'): normalizeTauriArgs([BigInt(10), BigInt(20)]) → expect [10, 20]
    - it('passes strings and numbers through unchanged'): normalizeTauriArgs('hello') → expect 'hello'；normalizeTauriArgs(42) → expect 42
    - it('handles null and undefined'): normalizeTauriArgs(null) → expect null；normalizeTauriArgs(undefined) → expect undefined

    **describe('tauriInvoke')**:
    - it('normalizes args and calls invoke'): mock invoke 返回 Promise.resolve('result')，调用 tauriInvoke('cmd', { num: BigInt(5) }) → expect invoke 被调用，参数为 ('cmd', { num: 5 })，返回 'result'
    - it('works without args'): mock invoke 返回 Promise.resolve('ok')，调用 tauriInvoke('cmd') → expect invoke 被调用
    - it('throws on invoke error'): mock invoke 返回 Promise.reject(new Error('fail'))，调用 tauriInvoke('cmd') → expect reject，错误消息包含 'fail'

    注意事项：
    - vi.stubGlobal('import.meta', {...}) 在 vitest 中可能需要用 vi.stubGlobal 直接操作，因为 import.meta 是只读的。如果 vitest 不允许 stub import.meta，替代方案：在测试文件顶部使用 vi.hoisted 和 vi.mock 配合 define 来替换环境变量。实际验证：vitest 支持 vi.stubGlobal 但 import.meta 通常是只读的。替代方案是使用 vitest 的 env 配置或手动在 setup 文件中注入。推荐使用 beforeEach 中直接覆盖 import.meta.env 的属性（在 vitest Node 环境中这些属性可写），然后在 afterEach 中恢复。
    - isDebugMode 内部读取 import.meta.env.DEV 和 import.meta.env.VITE_DEBUG。在 vitest node 环境中，这两个值默认不存在。测试时需要在每个 test 前手动设置 import.meta.env.DEV 和 import.meta.env.VITE_DEBUG 的值。

    - 具体：在测试中调用 ts_rs::export!() 宏（这是 ts-rs 推荐的批量导出方式），列出所有需要导出的类型

    导入路径（基于 narratoai-core/src/lib.rs 的 public modules）：
    - narratoai_core::documentary::types::DocumentaryRequest
    - narratoai_core::sde::types::SdeRequest
    - narratoai_core::sdp::types::SdpRequest
    - narratoai_core::script::types::{ScriptClip, OstType}

    - narratoai_core::llm::types::LlmResponseFormat

    使用 ts_rs::export! 宏，参数为导出目标路径。宏语法：
    ts_rs::export!({
      DocumentaryRequest,
      SdeRequest,
      SdpRequest,
      ScriptClip,
      OstType,

    fn export_ts_types() {
      DocumentaryRequest::export().unwrap();
      SdeRequest::export().unwrap();
      ...
    }
