# Plan 04: Integration Tests — End-to-End Pipeline Verification

<objective>
Write comprehensive integration tests that verify the complete documentary pipeline works end-to-end, each OST type independently, progress tracking, and the frame analysis → script generation flow.
</objective>

<tasks>

<task id="06-04-01" type="execute">
<read_first>
- src/documentary/pipeline.rs — run_documentary, all step functions
- src/documentary/script_gen.rs — generate_documentary_script
- src/documentary/types.rs — DocumentaryRequest, ScriptGenRequest
- src/documentary/clip.rs — OST clipping functions
- src/documentary/subtitle.rs — SRT generation
- src/script/types.rs — ScriptClip, OstType
- src/tts/mod.rs — TtsProvider, synthesize
- tests/conftest.py or existing test patterns — for integration test conventions
</read_first>
<action>
1. Create `tests/common/mod.rs` with shared test utilities:
   - `generate_test_video(output_path: &Path, duration_secs: f64, width: u32, height: u32) -> Result<()>`:
     - Use FFmpeg to generate a synthetic test video with color bars + tone audio
     - `ffmpeg -f lavfi -i color=c=blue:s={W}x{H}:d={dur}:r=30 -f lavfi -i sine=frequency=440:duration={dur} -c:v libx264 -preset ultrafast -pix_fmt yuv420p -c:a aac -shortest {output_path}`
   - `create_test_script(clips: Vec<(i64, &str, &str, &str, OstType)>) -> Script`:
     - Create ScriptClip objects with given parameters
   - `MockTtsProvider` — a TtsProvider impl that generates a short silent MP3 file and returns TtsOutput with synthetic word boundaries
     - Duration: based on text length (approximate 5 chars/sec)
     - Word boundaries: split text into words, distribute evenly across duration
   - `save_test_script(script: &Script, path: &Path)` — write script JSON to file

2. Create `tests/documentary_integration_test.rs` with integration tests:

   **Test: pipeline_ost0_narration_only**
   - Generate 10-second test video
   - Create script with 2 OST=0 clips (timestamps within video range)
   - Run pipeline with MockTtsProvider
   - Verify output video exists and has duration ≈ sum of TTS durations
   - Verify output video has no original audio track (ffprobe check)

   **Test: pipeline_ost1_original_sound**
   - Generate 10-second test video with audio
   - Create script with 2 OST=1 clips
   - Run pipeline
   - Verify output video exists
   - Verify output video has audio track (ffprobe)

   **Test: pipeline_ost2_mixed**
   - Generate 10-second test video with audio
   - Create script with 2 OST=2 clips
   - Run pipeline
   - Verify output video exists and has audio

   **Test: pipeline_mixed_ost_types**
   - Generate 30-second test video
   - Create script with 3 clips: OST=0, OST=1, OST=2
   - Run pipeline
   - Verify output video exists
   - Verify total duration matches expected

   **Test: pipeline_progress_tracking**
   - Run pipeline with a progress callback that records all (step, percent, message) tuples
   - Verify callback received all 6 steps in order
   - Verify percentages are non-decreasing
   - Verify final percentage is 100

   **Test: srt_generation_from_word_boundaries**
   - Create 5 WordBoundary entries with known offsets
   - Generate SRT content
   - Verify SRT has 5 blocks with correct timestamps and text

   **Test: subtitle_merge_with_offsets**
   - Create 2 SRT segments with different time offsets
   - Merge them
   - Verify merged output has sequential indices and correct offset timestamps

   **Test: timestamp_parsing_all_formats**
   - Test "00:01:30" → 90.0 seconds
   - Test "00:01:30,500" → 90.5 seconds
   - Test range "00:00:05-00:00:15" → (5.0, 15.0)
   - Test range "00:00:05,500-00:00:15,750" → (5.5, 15.75)

3. All tests must use `#[ignore]` attribute if FFmpeg is not available, with a helper that checks for FFmpeg and skips gracefully.
</action>
