# Plan 01: Foundation — Error Types, Request/State Structs, Timestamp Utilities, Module Setup

<objective>
Create the documentary module skeleton with all shared types that subsequent plans depend on: PipelineError, DocumentaryRequest, PipelineState, timestamp parsing utilities, and module exports.
</objective>

<tasks>

<task id="06-01-01" type="execute">
<read_first>
- src/error.rs — existing top-level NarratoError and module-level error patterns
- src/script/types.rs — ScriptClip, OstType definitions
- src/tts/mod.rs — TtsOutput, WordBoundary types
- src/config/types.rs — AppConfig structure
- src/ffmpeg/command.rs — ProgressCallback type, run_ffmpeg
- src/lib.rs — current module exports
- Cargo.toml — existing dependencies
</read_first>
<action>
1. Create `src/documentary/mod.rs` with public module declarations for `error`, `types`, `timestamp`, `pipeline`, `subtitle`, `audio`, `clip`, `script_gen`. Export key types at module level.

2. Create `src/documentary/error.rs`:
   - Define `PipelineError` enum with thiserror derive, variants:
     - `ScriptLoad { source: script::error::ScriptError }` — step 1 errors
     - `TtsGeneration { source: tts::TtsError }` — step 2 errors
     - `VideoClip(String)` — step 3 errors (message includes clip _id and OST type)
     - `AudioMerge(String)` — step 4 errors
     - `Concat(String)` — step 5 errors
     - `Composite(String)` — step 6 errors
     - `Io { source: std::io::Error }` — file system errors
     - `Timestamp(String)` — timestamp parsing errors
     - `SrtGeneration(String)` — subtitle generation errors
   - Implement `From<DomainError>` for each domain error type
   - Display impl must use Chinese messages (per Phase 1 D-18 pattern): e.g., "视频裁剪失败: {details}", "TTS 语音生成失败: {details}"

3. Create `src/documentary/types.rs`:
   - `DocumentaryRequest` struct with fields:
     - `video_path: PathBuf` — source video file
     - `script_path: PathBuf` — JSON script file
     - `tts_engine: String` — engine name (e.g. "edge_tts")
     - `voice_name: String` — TTS voice
     - `voice_rate: f64` — TTS speed (default 1.0)
     - `voice_pitch: f64` — TTS pitch (default 0.0)
     - `tts_volume: f64` — TTS audio volume (0.0-1.0, default 1.0)
     - `original_volume: f64` — original audio volume (0.0-1.0, default 0.7)
     - `bgm_volume: f64` — BGM volume (0.0-1.0, default 0.3)
     - `bgm_path: Option<PathBuf>` — BGM file
     - `subtitle_enabled: bool` — enable subtitle burning (default true)
     - `subtitle_font: Option<String>` — font path
     - `subtitle_font_size: u32` — font size (default 40)
     - `subtitle_color: String` — color (default "#FFFFFF")
     - `subtitle_position: String` — position (default "bottom")
     - `video_aspect: String` — aspect ratio (default "9:16")
     - `output_dir: Option<PathBuf>` — output directory override
     - `threads: u32` — FFmpeg threads (default 4)
   - `ProgressStep` enum: `LoadScript`, `Tts`, `Clip`, `MergeAudio`, `Concat`, `Composite`
   - `ProgressCallback` type: `Box<dyn Fn(ProgressStep, f32, &str) + Send + Sync>`
   - `TtsResult` struct: `{ clip_id: i64, audio_path: PathBuf, subtitle_path: PathBuf, duration: f64, word_boundaries: Vec<WordBoundary> }`

4. Create `src/documentary/timestamp.rs`:
   - `parse_timestamp_range(input: &str) -> Result<(f64, f64), PipelineError>` — parse "HH:MM:SS-HH:MM:SS" or "HH:MM:SS,sss-HH:MM:SS,sss" → (start_secs, end_secs)
   - `parse_time_to_secs(input: &str) -> Result<f64, PipelineError>` — parse "HH:MM:SS" or "HH:MM:SS,sss" → f64 seconds
   - `secs_to_srt_time(secs: f64) -> String` — convert f64 → "HH:MM:SS,mmm" (SRT format)
   - `secs_to_ffmpeg_time(secs: f64) -> String` — convert f64 → "HH:MM:SS.mmm" (FFmpeg format)
   - `calculate_end_time(start: &str, duration: f64) -> Result<String, PipelineError>` — given start "HH:MM:SS" and duration, calculate end time in same format
   - `format_clip_filename(ost: OstType, start: &str, end: &str) -> String` — generate filename like "ost0_vid_00-00-00-000@00-00-20-250.mp4"

5. Update `src/lib.rs`: add `pub mod documentary;`

6. Verify `Cargo.toml` has all needed dependencies (should already have: tokio, serde, serde_json, thiserror, ffmpeg-sidecar, tempfile, uuid, regex, chrono). No new dependencies needed.
</action>

<action>
1. Create `src/documentary/subtitle.rs`:
   - `generate_srt_from_word_boundaries(word_boundaries: &[WordBoundary], offset_secs: f64) -> String`:
     - Convert each WordBoundary (start_offset/end_offset in 100ns units) to SRT time format using `secs_to_srt_time()`
     - Add `offset_secs` to each timestamp (for positioning within final video)
     - Format as SRT blocks: index, timestamp line, text, blank line
   - `merge_srt_files(segments: &[SubtitleSegment]) -> Result<String, PipelineError>`:
     - `SubtitleSegment` has: `srt_content: String`, `offset_secs: f64`
     - Parse each SRT block, apply time offset, re-index sequentially
     - Return merged SRT content as String
   - `write_srt_file(content: &str, path: &Path) -> Result<(), PipelineError>` — write SRT to file

2. Add unit tests in `src/documentary/subtitle.rs`:
   - Test `generate_srt_from_word_boundaries` with 3 words: verify output has 3 SRT blocks, timestamps start at offset, format is correct
   - Test `merge_srt_files` with 2 segments at different offsets: verify sequential indexing and correct time offsets
   - Test edge case: empty word_boundaries produces empty SRT
</action>
