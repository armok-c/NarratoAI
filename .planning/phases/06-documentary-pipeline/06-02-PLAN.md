1. Define `PipelineState` in `src/documentary/pipeline.rs`:
```rust
pub struct PipelineState {
    pub task_id: String,
    pub task_dir: PathBuf,
    pub script: Script,
    pub tts_results: HashMap<i64, TtsResult>,
    pub video_clips: HashMap<i64, PathBuf>,
    pub merged_audio_path: Option<PathBuf>,
    pub merged_subtitle_path: Option<PathBuf>,
    pub combined_video_path: Option<PathBuf>,
    pub output_video_path: Option<PathBuf>,
    pub total_duration: f64,
    pub progress: Option<Box<dyn Fn(ProgressStep, f32, &str) + Send + Sync>>,
}
```

2. Implement `step_load_script(state: &mut PipelineState, script_path: &Path)`:
   - Call `script::load_script(script_path)`
   - Store result in `state.script`
   - Validate script has at least 1 clip
   - Log: "## 1. 加载视频脚本 — {N} 个片段"

3. Implement `step_tts(state: &mut PipelineState, engine: &str, voice_name: &str, rate: f64, pitch: f64)`:
   - Filter script clips where OST=0 or OST=2 (these need TTS)
   - For each filtered clip, call `tts::synthesize(engine, text, voice_name, rate, pitch, output_path)`
   - output_path = `{task_dir}/tts_{clip_id}.mp3`
   - After each TTS call, generate SRT fragment using `generate_srt_from_word_boundaries(word_boundaries, 0.0)` and save to `{task_dir}/subtitle_{clip_id}.srt`
   - Store results in `state.tts_results` keyed by clip _id
   - Use `futures::stream::iter().buffer_unordered(2)` for parallel TTS with concurrency limit 2
   - Progress: emit Tts step, 20%, "TTS 生成完成"
   - Log: "## 2. TTS 生成 — {N} 个片段"

4. Create `src/documentary/clip.rs` — OST-aware video clipping:
   - `clip_ost0_narration_only(video_path, clip, tts_result, task_dir, hwaccel) -> Result<PathBuf>`:
     - Parse timestamp start, calculate end from TTS duration (no extra seconds)
     - FFmpeg: `-ss {start} -to {end} -an` (remove audio)
     - Return clipped video path
   - `clip_ost1_original_sound(video_path, clip, task_dir, hwaccel) -> Result<PathBuf>`:
     - Parse full timestamp range (start-end)
     - FFmpeg: `-ss {start} -to {end} -c:a aac` (keep audio)
     - Return clipped video path
   - `clip_ost2_mixed(video_path, clip, tts_result, task_dir, hwaccel) -> Result<PathBuf>`:
     - Parse timestamp start, calculate end from TTS duration
     - FFmpeg: `-ss {start} -to {end} -c:a aac` (keep audio)
     - Return clipped video path
   - `clip_all_videos(state: &mut PipelineState, video_path: &Path)`:
     - Iterate all script clips, dispatch to OST-specific function
     - Store results in `state.video_clips`
     - Detect hardware acceleration via `hwaccel` module

5. Implement `step_clip(state: &mut PipelineState, video_path: &Path)`:
   - Call `clip_all_videos(state, video_path)`
   - Update script clips with `video`, `source_time_range`, `duration`, `edited_time_range` fields (port `update_script.py` logic):
     - `video` = clipped video path
     - `source_time_range` = actual clip time range from filename
     - `duration` = calculated from source_time_range
     - `edited_time_range` = cumulative position in final video
   - Calculate `state.total_duration` = sum of all clip durations
   - Progress: emit Clip step, 60%, "视频裁剪完成"
   - Log: "## 3. 视频裁剪 — {N} 个片段"

6. Create `src/documentary/audio.rs` — audio merging:
   - `merge_audio_files(state: &PipelineState) -> Result<PathBuf>`:
     - Create silent base of `state.total_duration` seconds via FFmpeg `anullsrc`
     - For each script clip with TTS result: overlay TTS audio at correct position using FFmpeg `adelay` + `amix`
     - OST=1 clips: no TTS audio, just advance position by duration
     - Output: `{task_dir}/merger_audio.mp3`
   - `merge_subtitle_files(state: &PipelineState) -> Result<Option<PathBuf>>`:
     - Collect all SRT fragments with their `edited_time_range` offsets
     - Use `merge_srt_files()` from subtitle.rs
     - Output: `{task_dir}/merged_subtitle.srt`

7. Implement `step_merge_audio_subtitle(state: &mut PipelineState)`:
   - Call `merge_audio_files(state)` → store in `state.merged_audio_path`
   - Call `merge_subtitle_files(state)` → store in `state.merged_subtitle_path`
   - Progress: emit MergeAudio step, 60%, "音频字幕合并完成"
   - Log: "## 4. 合并音频和字幕"

8. Implement `step_concat(state: &mut PipelineState)`:
   - Collect video clip paths in script order
   - Create concat file listing all clip paths (absolute paths, forward slashes)
   - FFmpeg concat demuxer: `ffmpeg -f concat -safe 0 -i concat_list.txt -c copy {output}`
   - If clips have different resolutions, re-encode to target resolution (scale+pad filter)
   - Output: `{task_dir}/merger.mp4`
   - Progress: emit Concat step, 80%, "视频拼接完成"
   - Log: "## 5. 合并视频 — {N} 个片段"

9. Implement `step_composite(state: &mut PipelineState)`:
   - Build FFmpeg complex filter chain based on available inputs:
     - Input 0: concatenated video (`merger.mp4`)
     - Input 1: merged TTS audio (`merger_audio.mp3`) — apply volume filter
     - Input 2: original audio from video (if any OST=1/2 clips exist) — apply volume filter
     - Input 3: BGM (if provided) — loop + fadeout + volume filter
   - Audio mixing: `[1:a]volume={tts_vol}[tts]; [2:a]volume={orig_vol}[orig]; [3:a]aloop=loop=-1:size=2e+09,volume={bgm_vol},afade=t=out:st={dur-3}:d=3[bgm]; [ tts][orig][bgm]amix=inputs=3:duration=longest[aout]`
   - If subtitle enabled AND SRT exists: add `subtitles={srt_path}` to video filter chain
   - Hardware-accelerated encoding if available
   - Output: `{task_dir}/combined.mp4`
   - Progress: emit Composite step, 100%, "最终合成完成"
   - Log: "## 6. 最终合成 — {output_path}"

10. Implement `pub async fn run_documentary(request: DocumentaryRequest) -> Result<PathBuf, PipelineError>`:
    - Create task_dir (using request.output_dir or default temp location)
    - Initialize PipelineState
    - Call steps 1-6 sequentially
    - Return output video path
    - Each step failure returns PipelineError immediately (fail-fast per D-06)

11. Update `src/documentary/mod.rs` to export `pipeline::run_documentary`, `pipeline::PipelineState`, `clip::*`, `audio::*`.

**Phase 6 — Plan 02 Threat Model**

| Threat | Severity | Mitigation |
|--------|----------|------------|
| FFmpeg command injection via crafted filenames | High | Sanitize all file paths before passing to FFmpeg; use Path API, reject special characters |
| Arbitrary file read via malicious subtitle_path in script JSON | Medium | Validate subtitle paths exist within task_dir |
| Resource exhaustion via extremely long video or many clips | Low | Add reasonable limits on clip count (max 1000) and total duration (max 2 hours) |
| FFmpeg process zombie if step panics | Medium | Use spawn_blocking with proper cleanup; implement Drop guard for temp files |

Block on: high severity threats — FFmpeg command injection must be mitigated with path sanitization
